Frankensurf is a Python package and needs Python 3.12 or newer. Pick your
system:

<Tabs syncKey="os">
<TabItem label="Linux">

<Steps>

1. Install the package with the MCP extra.

   ```bash
   python3 -m venv ~/.venvs/frankensurf && source ~/.venvs/frankensurf/bin/activate
   pip install "frankensurf[mcp]"
   ```

2. Download Chromium and the free stealth browsers (Camoufox, Scrapling, Patchright). This takes a few minutes.

   ```bash
   frankensurf setup
   ```

   If Chromium won't start, install its system libraries: `sudo $(which python) -m playwright install-deps chromium`.

3. Read a page, and see each tool it tried.

   ```bash
   frankensurf read "https://www.walmart.com/search?q=air+fryer" --explain
   ```

</Steps>

</TabItem>
<TabItem label="macOS">

<Steps>

1. Install Python 3.12 or newer if you don't have it, for example with
   [Homebrew](https://brew.sh/): `brew install python@3.12`.

2. Install the package, then Chromium and the free stealth browsers.

   ```bash
   python3 -m venv ~/.venvs/frankensurf && source ~/.venvs/frankensurf/bin/activate
   pip install "frankensurf[mcp]"
   frankensurf setup
   ```

3. Read a page, and see each tool it tried.

   ```bash
   frankensurf read "https://www.walmart.com/search?q=air+fryer" --explain
   ```

</Steps>

<Aside type="caution">
  macOS isn't part of our test runs yet. The core install is plain Python and
  Playwright, so it should behave as on Linux; please
  [open an issue](https://github.com/yail259/frankensurf/issues) if it doesn't.
</Aside>

</TabItem>
<TabItem label="Windows">

Frankensurf runs inside WSL (Windows Subsystem for Linux).

<Steps>

1. Install WSL with Ubuntu from an administrator PowerShell, then restart.

   ```powershell
   wsl --install -d Ubuntu
   ```

2. Open **Ubuntu** from the Start menu and follow the Linux steps there:

   ```bash
   sudo apt install -y python3-venv
   python3 -m venv ~/.venvs/frankensurf && source ~/.venvs/frankensurf/bin/activate
   pip install "frankensurf[mcp]"
   frankensurf setup
   sudo $(which python) -m playwright install-deps chromium
   frankensurf read "https://www.walmart.com/search?q=air+fryer" --explain
   ```

</Steps>

Your agent on Windows starts the server through WSL; see
[Add to your agent](/docs/agents/).

</TabItem>
</Tabs>

That is the free stack: plain HTTP, markdown negotiation, Jina Reader, a local
Chromium and the stealth browsers. No account or key. On the newest
[benchmark](/docs/more/benchmarks/) (150 fresh sites, v0.33) it reads 84.7% of
sites; adding the [paid tools](/docs/blocked/paid-tools/) takes it to 95.3%. Skip the stealth browsers with `frankensurf setup --no-stealth`.

## As a command-line tool

The package installs a `frankensurf` command (and `frankensurf-mcp` for agents).
To have it on your PATH without managing a virtual environment, install it as a
tool with [uv](https://docs.astral.sh/uv/) or [pipx](https://pipx.pypa.io/):

```bash
uv tool install "frankensurf[mcp]"     # or: pipx install "frankensurf[mcp]"
frankensurf setup
frankensurf read "https://news.ycombinator.com" --explain
```

`uv tool upgrade frankensurf` (or `pipx upgrade frankensurf`) updates it.

Working on Frankensurf itself? Install from a clone instead:
`git clone https://github.com/yail259/frankensurf.git`, then
`pip install -e '.[test,mcp]'` and `frankensurf setup`.

## Optional extras

Each one adds tools to the [escalation ladder](/docs/blocked/escalation/). The
scripts run in a shell (on Windows, inside WSL); SearXNG and Steel need
[Docker](https://docs.docker.com/get-docker/).

| Add | Command |
| --- | --- |
| Local search ([SearXNG](/docs/integrations/searxng/)) | `bash scripts/start-search.sh` |
| Self-hosted browser ([Steel](/docs/integrations/steel/)) | `bash scripts/start-steel.sh` |
| Stealth browsers ([Camoufox](/docs/integrations/camoufox/), [Scrapling](/docs/integrations/scrapling/), [Patchright](/docs/integrations/patchright/)) | `frankensurf setup` (included above) |
| [Crawl4AI](/docs/integrations/crawl4ai/) | `bash scripts/install-crawl4ai-provider.sh` |
| SOCKS connections for [the connection pool](/docs/blocked/egress/) | `pip install "frankensurf[socks]"` (tool install: `uv tool install "frankensurf[mcp,socks]"`) |
| Paid services | [Add keys](/docs/blocked/paid-tools/) |
