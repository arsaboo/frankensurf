Frankensurf is a Python package and needs Python 3.12 or newer. Pick your
system:

`frankensurf install` fetches every free tool in one go, the way `playwright
install` fetches browsers. Each lands in its own folder, never in your Python
environment, and one that fails leaves the others working:

| Tool | What it adds |
| --- | --- |
| `chromium` | Chromium for JavaScript pages |
| `stealth` | [Camoufox](/docs/integrations/camoufox/), [Scrapling](/docs/integrations/scrapling/) and [Patchright](/docs/integrations/patchright/) |
| `search` | A local [SearXNG](/docs/integrations/searxng/) on `127.0.0.1:8088`, no Docker |
| `crawl4ai` | [Crawl4AI](/docs/integrations/crawl4ai/) and its own browsers (Linux and WSL; not on macOS yet) |
| `nodriver` | [nodriver](/docs/integrations/nodriver/), only when you name it (AGPL-3.0) |

`frankensurf install search chromium` installs just those, `--with-deps` adds
the browsers' system libraries on Linux (it asks for sudo, as Playwright does),
`frankensurf install --list` shows what is installed where, and `frankensurf
uninstall all` (or `uninstall search`, ...) removes it again.

<Tabs syncKey="os">
<TabItem label="Linux">

<Steps>

1. Install the package with the MCP extra.

   ```bash
   python3 -m venv ~/.venvs/frankensurf && source ~/.venvs/frankensurf/bin/activate
   pip install "frankensurf[mcp]"
   ```

2. Install every free tool and the system libraries the browsers need (it asks for sudo). This takes a few minutes.

   ```bash
   frankensurf install --with-deps
   ```


3. Read a page, and see each tool it tried.

   ```bash
   frankensurf read "https://www.walmart.com/search?q=air+fryer" --explain
   ```

</Steps>

</TabItem>
<TabItem label="macOS">

<Steps>

1. Install Python 3.12 or newer if you don't have it, for example with
   [Homebrew](https://brew.sh/): `brew install python@3.12`.

2. Install the package, then every free tool.

   ```bash
   python3 -m venv ~/.venvs/frankensurf && source ~/.venvs/frankensurf/bin/activate
   pip install "frankensurf[mcp]"
   frankensurf install
   ```

3. Read a page, and see each tool it tried.

   ```bash
   frankensurf read "https://www.walmart.com/search?q=air+fryer" --explain
   ```

</Steps>

<Aside type="note">
  Each release is installed from PyPI on a fresh macOS machine (Apple silicon)
  and checked: install, every browser, a read and the MCP server. `frankensurf
  install` ends with `works_here`, which browsers started and read a page on your
  machine; please [open an issue](https://github.com/yail259/frankensurf/issues)
  if one doesn't.
</Aside>

</TabItem>
<TabItem label="Windows">

Frankensurf runs inside WSL (Windows Subsystem for Linux).

<Steps>

1. Install WSL with Ubuntu from an administrator PowerShell, then restart.

   ```powershell
   wsl --install -d Ubuntu
   ```

2. Open **Ubuntu** from the Start menu and follow the Linux steps there:

   ```bash
   sudo apt install -y python3-venv
   python3 -m venv ~/.venvs/frankensurf && source ~/.venvs/frankensurf/bin/activate
   pip install "frankensurf[mcp]"
   frankensurf install --with-deps
   frankensurf read "https://www.walmart.com/search?q=air+fryer" --explain
   ```

</Steps>

Your agent on Windows starts the server through WSL; see
[Add to your agent](/docs/agents/).

</TabItem>
</Tabs>

That is the free stack: plain HTTP, markdown negotiation, Jina Reader, a local
Chromium, the stealth browsers, Crawl4AI and your own search engine. No account,
key or Docker. On the newest
[benchmark](/docs/more/benchmarks/) (150 fresh sites, read once) it reads 88.0% of
sites, as many as the best paid tool on its own; adding the
[paid tools](/docs/blocked/paid-tools/) takes it to 96.0%.

<Aside type="note" title="Prefer to be asked? frankensurf setup">
  `frankensurf setup` is the guided install: Chromium and the stealth browsers
  (`--no-stealth` skips them), then it asks before installing local search and
  before adding the [agent skill](/docs/agents/) to `~/.claude/skills` (both
  default to no, and scripts and CI are never asked). `--search` and
  `--install-skill` say yes ahead of time; `--no-search` and
  `--no-install-skill` skip the questions.
</Aside>

## As a command-line tool

The package installs a `frankensurf` command (and `frankensurf-mcp` for agents).
To have it on your PATH without managing a virtual environment, install it as a
tool with [uv](https://docs.astral.sh/uv/) or [pipx](https://pipx.pypa.io/):

```bash
uv tool install "frankensurf[mcp]"     # or: pipx install "frankensurf[mcp]"
frankensurf install
frankensurf read "https://news.ycombinator.com" --explain
```

`uv tool upgrade frankensurf` (or `pipx upgrade frankensurf`) updates it.

Working on Frankensurf itself? Install from a clone instead:
`git clone https://github.com/yail259/frankensurf.git`, then
`pip install -e '.[test,mcp]'` and `frankensurf install`.

## Optional extras

Each one adds tools to the [escalation ladder](/docs/blocked/escalation/).
Everything free is in `frankensurf install` above; these are the rest.

| Add | Command |
| --- | --- |
| [nodriver](/docs/integrations/nodriver/) (AGPL-3.0, drives your own Chrome) | `frankensurf install nodriver` |
| Self-hosted browser ([Steel](/docs/integrations/steel/), needs [Docker](https://docs.docker.com/get-docker/)) | `bash scripts/start-steel.sh` (from a clone) |
| SOCKS connections for [the connection pool](/docs/blocked/egress/) | `pip install "frankensurf[socks]"` (tool install: `uv tool install "frankensurf[mcp,socks]"`) |
| Paid services | [Add keys](/docs/blocked/paid-tools/) |
