---
title: Settings
description: Every option a read, search or action accepts, with its default.
---

Every option is a field on `WebPolicy`, with a default. Nothing is hard-coded:
if a read stops, waits or skips something, an option here decides it.

- **Python**: pass `policy_overrides={...}` with only the options you mean.
- **CLI**: common options have flags; see [Command line](/docs/reference/cli/).
- **MCP**: pass them in `acquisition_policy`.

```python
await web.read(url, policy_overrides={"allow_paid_fallbacks": True, "max_cost_usd": 0.05})
```

Passing a whole `WebPolicy` instead fixes every option, which overrides a
site's route seed and returns `EXPLICIT_POLICY_CONFLICT` where they disagree.

These tables are generated from the code with `scripts/web_policy_doc.py`.

## Fetching

| Field | Default | What it does |
| --- | --- | --- |
| `freshness` | `"now"` | `now` always fetches; `hour`, `day` and `cached` may reuse a saved copy. |
| `render` | `False` | Require a browser; skips providers that cannot render. |
| `prefer_markdown` | `False` | Ask servers for `text/markdown` first (T0). |
| `sign_requests` | `True` | Sign plain HTTP reads with Web Bot Auth when a key exists (T3). |
| `timeout_seconds` | `25` | Time allowed for each provider attempt. |
| `unblocker_timeout_seconds` | `90.0` | Time allowed for an unblocker attempt. |
| `agent_provider_timeout_seconds` | `300.0` | Time allowed for an agent provider such as Skyvern. |
| `max_bytes` | 40 MB | Largest response accepted. |
| `pdf_max_pages` | `50` | Most PDF pages to extract text from. Also the most pages a paid tool such as Firecrawl is asked to parse, since it bills per page. A longer PDF is cut short and says so: `structured.truncated` and `receipt.pdf`. |
| `capture_json_responses` | `False` | On rendered reads, return the JSON the page fetched for itself as `captured_json`. |
| `capture_json_max_items` | `20` | Most captured JSON responses kept. |
| `capture_json_max_bytes` | 2 MB | Largest captured JSON response kept. |
| `include_images` | `False` | Download and check the page's images. |
| `max_images` | `50` | Most images to download. |
| `card_images` | `False` | Add `cards`: each result link with its title and own thumbnail URL. |
| `include_links` | `False` | Add `links`: every link on the page (`url`, `text`), in page order, once each. |
| `max_links` | `500` | Most links `include_links` returns. |
| `scroll_screens` | `0` | Screens a browser scrolls before capture so lazy content loads (3 with `card_images`). |
| `expect_terms` | `()` | Words search results should mention besides the URL query; results that mention none are flagged `off_query`. |
| `main_content` | `False` | Also return `main_text`: the article without menus, footers and banners. |
| `interactions` | `()` | Safe browser actions on browser reads: `dismiss_consent` (reject, never accept), `load_more`, `reveal`. |
| `auto_items` | `False` | Items from any listing page with no saved module, found in the page's own data; the draft module comes back too. |
| `max_image_bytes` | 20 MB | Largest image accepted. |
| `image_max_attempts` | `2` | Attempts per image. |
| `image_retry_delay_seconds` | `0.25` | Delay between image attempts. |
| `image_retry_failures` | `PROVIDER_DOWN`, `TIMEOUT` | Image failures worth another attempt. |
| `retain_public_failure_evidence` | `True` | Keep evidence of failed public reads. |

## Routing and cost

| Field | Default | What it does |

| `use_egress_pool` | `True` | Let a walled read try your other connections (FRANKENSURF_EGRESS). |
| `egress_failures` | `BLOCKED`, `CAPTCHA`, `RATE_LIMITED` | Failures that start a pass through your other connections. |
| `egress_tools` | `camoufox`, `scrapling`, `http` | Tools a pass through another connection uses; the wall vendor's best goes first. |
| `allow_archive` | `False` | A stored copy (Internet Archive) as the very last resort; the result says when it was taken. |

| `exclude_providers` | `()` | Skip these providers (the agent's try-harder lever). |
| `try_harder` | `False` | Order the remaining providers strongest first, paid ones included when allowed. |
| `retry_of_trace` | `None` | The trace this read retries, for the receipt. |
| `terminal_failures` | `AUTH_REQUIRED`, `AUTH_EXPIRED`, `NOT_FOUND` | Failures that stop the climb. |

| `auth_wall_confirmations` | `5` | Providers in a row that must hit a sign-in wall before a public read stops. |

| `use_route_memory` | `True` | Let route memory reorder providers. |
| `use_wall_priors` | `True` | Start wall-vendor routing from measured priors on a fresh install; your own reads outweigh them. |
| `route_memory_ttl_seconds` | `3600` | How far back route memory looks. |
| `route_memory_min_samples` | `3` | Clean reads in a row before a provider is promoted. |
| `origin_route_hint_ttl_seconds` | `86400.0` | How long a site hint lasts. |
| `provider_max_attempts_per_candidate` | `2` | Attempts per provider. Paid and capped reads are never retried. |
| `provider_retry_delay_seconds` | `1.0` | Delay between attempts. |
| `provider_retry_failures` | `PROVIDER_DOWN` | Failures worth another attempt. |
| `provider_deadline_grace_seconds` | `10` | Extra time an isolated worker gets past `timeout_seconds`. |
| `provider_cleanup_grace_seconds` | `5` | Time allowed to close a provider's process tree. |
| `provider_composition_max_depth` | `8` | Deepest nesting when one provider calls another. |
| `provider_composition_max_attempts` | `64` | Most nested provider attempts in one operation. |
| `compound_source_candidates` | `http`, `camoufox`, `scrapling` | Validated provider list reserved for compound routes; not used by the default route. |

## Search and paging

| Field | Default | What it does |
| --- | --- | --- |
| `search_source_candidates` | `None` | An exact ordered list of search sources. |
| `search_source_allow` | `None` | Only these sources may run. |
| `search_source_prefer` | `()` | Move these sources to the front. |
| `search_max_attempts` | `None` | Most sources to try. |
| `search_source_timeout_seconds` | `8` | Time per source; `None` uses the operation timeout. |
| `search_terminal_failures` | `POLICY_DENIED`, `BUDGET_EXHAUSTED` | Failures that stop search fallback. |
| `search_merge_sources` | `4` | Sources asked at once by `search(mode="merge")`. |
| `search_ladder` | `True` | An automatic search climbs sources until a result set passes the checks (on the query, inside the date window, real pages, deduplicated), carrying passing results up; false keeps the first answer. |
| `search_good_results` | `3` | Passing results that make a set good (or the limit, if lower). |
| `search_date_reads` | `6` | A windowed automatic search (`recency`) reads up to this many undated results' pages per source's result set (twice as many per search) over plain http, with no paid tool, to find their publication date; results provably outside the window drop out, and ones still undated count for at most half of `search_good_results`. 0 turns it off. |
| `search_date_read_timeout_seconds` | `5.0` | Time one such date read gets, in seconds. |
| `search_hold_undated` | `True` | In a windowed automatic search, results whose publication date could not be verified are left out of `results` whenever any verified in-window results exist, and returned apart as `unverified_results`. False mixes them in, ranked after the verified ones. |
| `search_fill_rungs` | `2` | In a windowed automatic search, once the answer is good, up to this many more free sources are asked while it holds fewer verified in-window results than the limit, and what passes is merged in. Without a window, one more free source is asked when local SearXNG is reachable and the answer holds fewer passing results than the limit. Never a paid or last-resort source. 0 turns it off. |
| `search_hedge_after_seconds` | `3.0` | After this long without an answer, the next free search source starts beside the current one; 0 turns it off. |
| `search_hedge_racers` | `2` | Search sources running at once while racing, 1 to 3. Paid sources never race. |
| `search_max_seconds` | `30.0` | Ceiling for one whole search, in seconds. |
| `search_max_sources` | `6` | Ceiling on search sources started in one search. |
| `search_paid_after_weak` | `2` | Weak or empty free sources before allowed paid search sources join, cheapest likely success first; 0 leaves them until every free source has been tried. |
| `search_paid_parallel` | `True` | With `allow_paid_fallbacks`, an automatic search starts the cheapest likely-success paid search source beside the first free rung instead of after the free ones fail, whatever the kind of query. Everything is merged, checked and ranked, and a paid result that fails the checks gives way to a passing free one. The cost cap applies. False keeps paid sources behind the free rungs. |
| `search_paid_wait_seconds` | `10.0` | When the free sources make the answer good while the parallel paid source is still running, wait this many seconds for it, so the answer can be anchored on it. If it does not answer in time, the free answer stands, `search_ladder.anchor` is null with the note `paid_timeout`, and the cancelled call is costed at its bundled price per search (marked estimated). 0 does not wait. |
| `search_learned_routing` | `True` | Try first the source that most often passed the checks for this kind of query (vertical, recency, site filter). |
| `search_exclude_operators` | `3` | Most -site: operators sent to an engine; the whole exclude list is enforced on the results either way. |
| `max_pages` | `2` | Most pages `paginate` follows. |
