## Environment variables

| Variable | What it sets |
| --- | --- |
| `FRANKENSURF_STATE` | State directory for the MCP server. |
| `FRANKENSURF_PLUGINS` | The plugin trust file (default `~/.config/frankensurf/plugins.json`); see [Writing a plugin](/docs/more/plugins/#the-trust-file). |
| `FRANKENSURF_STEEL_URL` | A self-hosted Steel for the `steel` provider. |
| `FRANKENSURF_SEARCH_URL` | A SearXNG at another loopback address (MCP server). Not needed for the one `frankensurf install search` starts, at `http://127.0.0.1:8088`. |
| `FRANKENSURF_GOOGLE_CSE_CX` | The search engine ID for [Google Programmable Search](/docs/integrations/google-cse/), beside `GOOGLE_CSE_API_KEY`. |
| `FRANKENSURF_SEARCH_AUTOSTART` | `0`: search never starts the installed local SearXNG on its own (by default it does, once per process, when nothing answers on `127.0.0.1:8088`). |
| `FRANKENSURF_IDENTITIES` | Identity registry (default `~/.frankensurf/identities.json`). |
| `FRANKENSURF_PROVIDER_PYTHON` | Python for the isolated stealth browsers. |
| `FRANKENSURF_CRAWL4AI_DIR`, `FRANKENSURF_CRAWL4AI_PYTHON`, `FRANKENSURF_CRAWL4AI_BROWSERS_PATH`, `FRANKENSURF_CRAWL4AI_HEALTH` | The isolated Crawl4AI install. |
| `FRANKENSURF_BROWSER_USE_PYTHON`, `FRANKENSURF_BROWSER_USE_BROWSER`, `FRANKENSURF_BROWSER_USE_MODEL_FACTORY`, `FRANKENSURF_BROWSER_USE_BILLING`, `FRANKENSURF_BROWSER_USE_BINDING_REVISION` | The Browser Use agent. |
| `FRANKENSURF_SIGNATURE_AGENT`, `FRANKENSURF_BOT_AUTH_KEY_FILE` | [Signed requests](/docs/blocked/signed-requests/). |
| `FRANKENSURF_HANDOFF_PROFILE`, `FRANKENSURF_HANDOFF_CDP_URL` | [Handoff](/docs/blocked/handoff/). |
| `FRANKENSURF_REAL_BROWSER`, `FRANKENSURF_REAL_BROWSER_PATH`, `FRANKENSURF_REAL_BROWSER_PROFILE`, `FRANKENSURF_REAL_BROWSER_CDP`, `FRANKENSURF_REAL_BROWSER_WINDOW` | [Your real browser](/docs/blocked/real-browser/): `1` turns it on for every read. |
| `FRANKENSURF_EGRESS` | [Your other connections](/docs/blocked/egress/), `name=url`, for walled reads. |
| `FRANKENSURF_LIGHTNING` | `1` turns [lightning mode](/docs/read/lightning/) on for every read. Both switches also work in `~/.config/frankensurf/.env`, and both are defaults: a call that sets the field itself wins. |
| `FRANKENSURF_<SERVICE>_API_KEY` and rate settings | Paid services. See [Keys and costs](/docs/blocked/paid-tools/). |

## Files

| Path | What it holds |
| --- | --- |
| `./state/` (or `--state`) | Cache, evidence, traces, route memory, `origin-pacing.json`, `watches/`. |
| `~/.config/frankensurf/.env` | Keys and settings as `FRANKENSURF_…=…` lines. |
| `~/.config/frankensurf/services.json` | Keys under `api_keys`. |
| `~/.config/frankensurf/web-bot-auth.jwk` | Your Web Bot Auth private key. |
| `~/.config/frankensurf/browser-agent.json` | Browser Use model configuration. |
| `~/.config/frankensurf/plugins.json` | Which installed third-party plugins to trust. |
| `~/.frankensurf/identities.json` | Registered executors and identities. |
| `~/.local/share/frankensurf/handoff-profile/` | The handoff browser profile. |
| `~/.local/share/frankensurf/crawl4ai-venv/` | The Crawl4AI environment. |

Keep everything under `~/.config/frankensurf` readable only by you.
