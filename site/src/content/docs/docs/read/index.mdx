title: Read a page
description: Turn any URL into clean text or markdown, with its structured data and a receipt.

import { Tabs, TabItem, Aside } from "@astrojs/starlight/components";

`read` gets a page through whatever is in the way and hands over everything on
it.

- Tries the cheapest tool first and [climbs](/docs/blocked/escalation/) when a
  page pushes back: app shells, challenges and empty renders count as failures,
  not thin successes.
- Handles JavaScript apps, PDFs, JSON APIs and signed-in pages.
- Returns text or markdown, JSON-LD, the page's embedded JSON, image URLs and a
  receipt.

## Usage

<Tabs syncKey="lang">
<TabItem label="Python">

```python
import frankensurf as fs

page = fs.read("https://developer.mozilla.org/en-US/docs/Web/HTTP")
if page.ok:
    print(page.title)
    print(page.text[:500])
else:
    print("couldn't read it:", page.failure)   # the code and why, never a stand-in page
```

`fs.read` takes `paid=True`, `max_cost=`, `main=True`, `links=True`, `provider=` and
`try_harder_than=`, and any other [setting](/docs/reference/settings/) as a keyword. `page` is the
full result dict with shortcuts: `ok`, `failure`, `title`, `text`, `links`, `via`, `cost_usd`,
`trace_id`. Inside async code use `await fs.aread(...)`; for many pages, `fs.batch(urls)`. A
long-running service keeps one `Runtime` open instead:

```python
from frankensurf import Runtime

async with Runtime() as web:
    page = await web.read("https://developer.mozilla.org/en-US/docs/Web/HTTP")
```

## Response

| Field | Description |
| --- | --- |
| `url` | Final URL after redirects. |
| `title` | Page title. |
| `text` | Readable text, or markdown when the site sent markdown. |
| `structured` | JSON-LD and embedded JSON for HTML; the parsed body for JSON; page count for PDFs. See [Page data](/docs/read/page-data/). |
| `image_urls` | Images found on the page. |
| `content` | The raw body. The CLI leaves it out unless you pass `--raw`; MCP always leaves it out. |
| `receipt` | Which tools ran, how long each took, what it cost. See [Receipts](/docs/reference/receipts/). |

## Options

Pass options as `policy_overrides` in Python, flags on the CLI, or
`acquisition_policy` over MCP.

| Option | Default | Description |
| --- | --- | --- |
| `prefer_markdown` | `false` (`true` over MCP) | Ask the site for [markdown](/docs/read/markdown/) first. |
| `render` | `false` | Skip plain HTTP and use a [browser](/docs/read/javascript/). |
| `freshness` | `"now"` | `hour`, `day` or `cached` may reuse a saved copy. |
| `include_images` | `false` | Download and check [images](/docs/read/images/). |
| `allow_paid_fallbacks` | `false` | Let [paid tools](/docs/blocked/paid-tools/) join when free ones fail. |
| `allow_handoff` | `false` | Let a [person](/docs/blocked/handoff/) clear the last wall. |
| `identity` | none | Read [signed in](/docs/read/signed-in/) as you. |
| `timeout_seconds` | `25` | Time allowed for each tool. |

Every option is listed in [Settings](/docs/reference/settings/).

<Aside type="note">
  A failed read still returns a result: `receipt.status` is `"failed"` and
  `receipt.failure` says why. See [Errors](/docs/reference/errors/).
</Aside>
