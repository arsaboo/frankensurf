The free stack needs no keys. Paid tools join a read only when two things are
true: the key is set, and the call allows it.

- Paid tools are tried after the free ones, until a wall: then they move ahead
  ([escalation](/docs/blocked/escalation/), `paid_after_walls`, after the first
  wall by default, or the second when a free tool usually gets past that wall
  vendor).
- Cheapest likely success first: each paid tool's measured cost per read over
  its chance of getting past this wall vendor (bundled measurements: Firecrawl
  passed 88 to 100% of the labelled Cloudflare, Akamai, DataDome and PerimeterX
  sites at $0.004 a read; ZenRows 29 to 50% at $0.025). Your own reads update
  the chances.
- They are never retried automatically.
- A tool without a key is skipped, not failed.

## Usage

<Tabs syncKey="lang">
<TabItem label="Python">

```python
page = await web.read(url, policy_overrides={
    "allow_paid_fallbacks": True,
    "max_cost_usd": 0.05,
})
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "read", "arguments": { "url": "https://www.g2.com/",
  "acquisition_policy": { "allow_paid_fallbacks": true, "max_cost_usd": 0.05 } } }
```

</TabItem>
</Tabs>

`receipt.cost_usd` is the total measured cost. If any tool's cost is unknown,
the total is `null`, never a guess.

## Add keys

Frankensurf looks for each key in this order:

1. the environment, as `FRANKENSURF_<NAME>`;
2. `~/.config/frankensurf/.env`;
3. the `api_keys` object in `~/.config/frankensurf/services.json`.

```bash title="~/.config/frankensurf/.env"
FRANKENSURF_ZENROWS_API_KEY=...
FRANKENSURF_FIRECRAWL_API_KEY=...
FRANKENSURF_EXA_API_KEY=...
```

Keep the file readable only by you (`chmod 600`). With a secrets manager such as 1Password,
Doppler or Infisical, store the keys under these names and run through it, for
example `op run -- frankensurf read …`. Keys never appear in results,
receipts or errors.

## Budgets

`max_cost_usd` caps the whole read, fallbacks included. Tools that can bound
their worst case (ZenRows, Firecrawl and the hosted browsers) refuse a call that
could pass what's left, with `BUDGET_EXHAUSTED`. Tools that can't report cost
don't run under a cap.

<Aside type="note">
  Hosted browsers bill by session time. The default rates are list prices; set
  yours with `FRANKENSURF_<ID>_USD_PER_HOUR`, for example
  `FRANKENSURF_BROWSERBASE_USD_PER_HOUR=0.10`.
</Aside>
