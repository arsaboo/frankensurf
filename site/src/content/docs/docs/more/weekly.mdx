Every Monday a fresh GitHub machine reads the same 150 sites (held-out set 7, picked blind on 10
October 2026), once with each tool on its own and once with Frankensurf. Every read is judged by the
same content checks as the [launch benchmark](/docs/more/benchmarks/). The sites stay the same so the
trend means something. Sites change, tools change, and this shows whether the result holds.

**[See it charted: every site, every tool, speed and trend →](/benchmarks/)**

It runs from a data-centre address, which sites wall more often than a home connection, so every
rate here is lower than the headline numbers. Compare the tools with each other, week by week.
Paid tools appear when their keys are configured for the run.
