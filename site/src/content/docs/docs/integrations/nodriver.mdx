[nodriver](https://github.com/ultrafunkamsterdam/nodriver) drives Chrome over the DevTools protocol directly, with no WebDriver layer to detect. It runs in the same isolated environment as Camoufox.

- Free and local.
- nodriver doesn't report the page's HTTP status, so its reads count as 200 and rely on Frankensurf's content checks.
- Pin 0.47.0: later versions ship a file Python 3.14 refuses to import.

## Set up

```bash
~/.local/share/frankensurf/provider-venv/bin/pip install "nodriver==0.47.0"
```

## Use it

It is optional: `frankensurf install` installs it only when you name it (`frankensurf install nodriver`), and reports it as `not installed (optional)` otherwise. Until you install it, the default route skips it, and pinning it fails with `PROVIDER_UNAVAILABLE`. Once installed it joins the default route by itself, and `setup` checks it in `works_here`. To use it on its own:
