[Crawl4AI](https://github.com/unclecode/crawl4ai) 0.9.4 runs in a separate Python environment with its own browsers, so its dependencies never touch Frankensurf's.

- Pinned to an exact package lock; every dependency is hash-checked before each run.
- Uses its own browser cache, never the shared Playwright one.
- Any change to the install makes the provider unavailable instead of running unchecked code.

## Set up

```bash
frankensurf install crawl4ai      # part of plain `frankensurf install` too
```

On Linux (on Windows, inside WSL); not on macOS yet, where its environment checks do not pass. The installer creates `~/.local/share/frankensurf/crawl4ai-venv` and ends with a live render check. Move it with `FRANKENSURF_CRAWL4AI_DIR`, `FRANKENSURF_CRAWL4AI_PYTHON` and `FRANKENSURF_CRAWL4AI_BROWSERS_PATH`.

## Use it

It joins the default route by itself once set up. To use it on its own:

<Tabs syncKey="lang">
<TabItem label="Python">

```python
page = await web.read(
    "https://example.com/products/2231",
    provider="crawl4ai",
)
```

</TabItem>
<TabItem label="CLI">

```bash
frankensurf read https://example.com/products/2231 --provider crawl4ai
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "read", "arguments": { "url": "https://example.com/products/2231", "provider": "crawl4ai" } }
```
