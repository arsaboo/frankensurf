Reads Bing's RSS search results. It's the last web source an automatic search
asks, and it never races another source. If every result in an answer shares
nothing with the query, the source counts as failed (`SEARCH_UNAVAILABLE`,
"results unrelated to the query") rather than as an answer.

- No key needed.
- Fetched through the `http` provider, so pacing applies.
- Results are indexed candidates; read them to confirm.

## Set up

Built in.

## Use it

Ask for this source by name. Named sources never fall back to another.

<Tabs syncKey="lang">
<TabItem label="Python">

```python
results = await web.search("playwright python tutorial", source="bing_rss")
```

</TabItem>
<TabItem label="CLI">

```bash
frankensurf search playwright python tutorial --source bing_rss
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "search", "arguments": { "query": "playwright python tutorial", "source": "bing_rss" } }
```

</TabItem>
</Tabs>
