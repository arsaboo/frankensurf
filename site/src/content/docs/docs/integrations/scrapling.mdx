[Scrapling](https://github.com/D4Vinci/Scrapling) provides three providers, all running in an isolated worker process.

- `scrapling`: the stealth browser fetcher (T3).
- `scrapling_http`: an HTTP fetcher with a browser-like TLS fingerprint (T1).
- `scrapling_ready`: the stealth browser waiting for a site's ready signal; runs only through a route seed or when named.

## Set up

```bash
frankensurf install stealth
```

## Use it

It joins the default route by itself once set up. To use it on its own:

<Tabs syncKey="lang">
<TabItem label="Python">

```python
page = await web.read(
    "https://example.com/products/2231",
    provider="scrapling",
)
```

</TabItem>
<TabItem label="CLI">

```bash
frankensurf read https://example.com/products/2231 --provider scrapling
```

</TabItem>
<TabItem label="MCP">

```json
{ "tool": "read", "arguments": { "url": "https://example.com/products/2231", "provider": "scrapling" } }
```

</TabItem>
