Frankensurf builds none of its tools. It stitches the best ones together and
routes each page to the cheapest one that works. Free tools join by themselves
once installed; paid ones join when their key is set and the call allows paid
tools.

**Tested** means: **Live**, a real read through Frankensurf against a real site
or the real service; **Mocks**, checked against the service's published API
format only. A mock isn't done: add the key and run one read to promote it.
A key also works under the service's own name (`SCRAPFLY_API_KEY`, `ZYTE_API_KEY`
and so on); the `FRANKENSURF_` name wins when both are set.

<Aside type="note" title="Pairs with Frankensurf">
  [Stagehand](https://github.com/browserbase/stagehand) and
  [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp)
  drive a browser step by step rather than fetch pages, so they aren't
  providers. An agent can use either alongside Frankensurf's `read` for pages
  that need clicking through.
</Aside>
